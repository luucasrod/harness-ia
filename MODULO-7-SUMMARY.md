## CONTEXTO UNIFICADOR

Todas as lições do Módulo 7 usam **plataforma educacional com tutor de IA** como contexto central:

### Fio Narrativo Módulo 7

```
Problema Inicial:
  UserManager faz validação, persistência, e-mail, pagamento, analytics
  
Lição 7.1 (SRP):
  Divide em UserValidator, UserRepository, EmailService, etc.
  UserService orquestra
  
Lição 7.2 (Open/Closed + outros):
  ExerciseGrader usa Strategy (não if-else gigante)
  Novo tipo de exercício = nova Strategy, sem editar código existente
  
Lição 7.3 (Creational):
  ExerciseFactory cria diferentes tipos
  LessonBuilder constrói lições complexas
  
Lição 7.4 (Structural/Behavioral):
  AiTutorService com Decorator (cache, retry, rate limiting)
  Observer: LessonCompleted dispara e-mail, analytics, certificado
  
Lição 7.5 (DDD):
  Lesson é Aggregate (raiz)
  Exercise é entidade filha
  LessonCompleted é evento de domínio
  
Lição 7.6 (Refactoring):
  Refatore tudo junto aplicando todas as técnicas aprendidas
```
